POLLOS LOS CAMPOS — EJECUCIÓN LOCAL
====================================

REQUISITOS
  - JDK 21 o superior (no se necesita instalar Maven: se incluye mvnw).
  - No se necesita MySQL ni XAMPP: la base H2 viene embebida.

PASOS (desde la carpeta raíz, donde está pom.xml)
  1. Pruebas:    Windows: .\mvnw.cmd clean test        Linux/Mac: ./mvnw clean test
  2. Ejecutar:   Windows: .\mvnw.cmd spring-boot:run   Linux/Mac: ./mvnw spring-boot:run
  3. Abrir:      http://localhost:8080

  NUNCA compilar con "javac Archivo.java": es un proyecto Maven.

USUARIOS DE PRUEBA
  Administrador: admin@pollosloscampos.local / Admin123!
  Cliente:       se crea desde /registro (o cliente@correo.com / Cliente123! si se carga el script SQL)

OPCIONAL: USAR MYSQL / MARIADB
  1. Ejecutar los scripts de /database (ver database/README-BD.md) o restaurar el backup.
  2. Editar src/main/resources/application-mysql.properties (usuario y clave).
  3. ./mvnw spring-boot:run -Dspring-boot.run.profiles=mysql

BACKUP Y SCRIPTS DE BASE DE DATOS
  database/pollos_los_campos.sql                    script completo
  database/01_esquema.sql, 02_..., 03_..., 04_...   scripts por etapas
  database/backup/backup_pollos_los_campos.sql      backup con datos, procedimientos y triggers

CAPTURAS DE PANTALLA AUTOMÁTICAS (para el informe)
  pip install playwright && playwright install chromium
  python docs/capturas/tomar_capturas.py            (con la aplicación en ejecución)

REINICIAR DATOS H2
  Detener la aplicación y borrar database/pollos_los_campos.mv.db; al iniciar se vuelve a sembrar.
